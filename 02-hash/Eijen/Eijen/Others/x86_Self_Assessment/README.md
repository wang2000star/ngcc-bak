# Eijen x86 自评估材料

本目录按 x86 自评估指引的材料命名方式组织，目录名采用“算法类别-算法名-x86-实现版本”：

- `密码杂凑-Eijen-x86-参考实现版`
- `密码杂凑-Eijen-x86-性能优化版`
- `密码杂凑-Eijen-x86-资源优化版`

每个版本目录均包含：

- `algorithm_source/`：算法源代码。
- `self_assessment/`：自评估测试代码、测试数据、原始结果。
- `docs/dependencies.md`：依赖说明。
- `自评估报告.md`：自评估报告。
- `README.md`：该版本的构建和复核说明。
