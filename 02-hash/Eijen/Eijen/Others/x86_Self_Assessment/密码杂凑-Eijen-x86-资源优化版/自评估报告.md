# 密码杂凑-Eijen-x86-资源优化版自评估报告

本文档是 `密码杂凑-Eijen-x86-资源优化版` 的 x86 架构实现自评估报告，作为提交包内该实现版本的可复核技术证据。

## 1. 算法基本信息

- 算法类别：密码杂凑算法
- 算法名称：Eijen
- 细分功能：杂凑值生成
- 实现版本：资源优化版
- 参数集：Eijen-256、Eijen-384、Eijen-512、Eijen-768、Eijen-1024
- 输出摘要长度：32、48、64、96、128 bytes

## 2. 材料目录

- 算法源代码：`algorithm_source/include/eijen.h`、`algorithm_source/src/eijen_ref.c`、`algorithm_source/src/eijen_internal.h`
- 自评估代码：`self_assessment/tests/eijen_kat.c`、`self_assessment/tools/eijen_bench.c`
- 自评估数据：`self_assessment/data/eijen_kat.tsv`
- 自评估脚本：`self_assessment/run_self_assessment.sh`
- 原始结果：`self_assessment/results/`
- 依赖说明：`docs/dependencies.md`

## 3. 实现说明

资源优化实现，复用 C99 scalar 实现并采用尺寸优先编译选项；实现支持流式处理，不需要一次性加载完整消息。

编译配置为：`gcc -Os -march=x86-64 -mavx2 -flto -fomit-frame-pointer -std=c99 -Wpedantic -Wall -Wextra`。

## 5. 测试命令

在本目录下执行：

```sh
self_assessment/run_self_assessment.sh
```

该脚本会执行以下复核步骤：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 1
ctest --test-dir build --output-on-failure
build/bench > self_assessment/results/bench.csv
```

并同步生成 `environment.txt`、`static_size.txt` 和 `time.txt`。

## 7. 性能测试

性能测试覆盖 x86 指引规定的 S1-S8 输入长度：

| 级别 | 输入长度 |
| --- | ---: |
| S1 | 32 Bytes |
| S2 | 128 Bytes |
| S3 | 512 Bytes |
| S4 | 1024 Bytes |
| S5 | 4096 Bytes |
| S6 | 8192 Bytes |
| S7 | 16384 Bytes |
| S8 | 65536 Bytes |


`self_assessment/tools/eijen_bench.c` 对每个测试项执行 `repetitions=5` 次重复，并在每次重复内执行 CSV 中记录的 `iterations` 次核心杂凑操作；所有 S1-S8 测试项的 `iterations` 均不小于 200。cycle 计数使用序列化 TSC 读数，并输出 digest checksum，避免测量循环被优化弱化。完整明细见 `self_assessment/results/bench.csv`。

## 8. 资源消耗测试

静态尺寸由 `size build/kat build/bench` 生成，峰值内存由 `/usr/bin/time -v build/bench` 生成。原始证据见 `self_assessment/results/static_size.txt` 和 `self_assessment/results/time.txt`。

| 目标 | text | data | bss | dec |
| --- | ---: | ---: | ---: | ---: |
| `kat` | 9694 | 1128 | 8 | 10830 |
| `bench` | 6257 | 776 | 16 | 7049 |

| 目标 | Maximum resident set size |
| --- | ---: |
| `bench` | 1600 KB |

实现侧内存占用还包括：

- `sizeof(eijen_ctx) = 488` bytes；
- 单消息吸收每次最多使用 `saved_cap[17] = 136` bytes 栈临时区；
- 性能优化版四路短消息快路径使用 AVX2 状态数组，约 `32 * 32 = 1024` bytes 栈空间；参考实现版和资源优化版不使用该四路 AVX2 快路径。

## 9. 传输与存储开销

Eijen 是密码杂凑算法，不涉及公钥、私钥、签名、密文或密钥交换消息尺寸；本项不适用。输出摘要长度为 32、48、64、96、128 bytes。
