The current S6 performance entry point is:

```text
docs/perf/AFS-TrEDM-S6_Performance_Report.md
```

Use that report for Stage S6 submission claims. Older benchmark engineering
subdirectories under `docs/perf/` are not part of the strict final submission
tree; current live evidence is retained under `docs/perf/live/latest/`.

Stage16 live performance evidence is regenerated with:

```text
bash scripts/run_live_perf_tables_s6.sh \
  --root /home/weibh/Codex/AFS-TrEDM_Submission_v2.0 \
  --mode full \
  --instances 512,768,1024 \
  --include-sha3 \
  --include-sha3-reference
```

The active live output separates AFS-TrEDM-S6 internal implementation tables
from SHA3-512 baseline tables. AFS internal tables cover 512, 768, and 1024.
AFS-TrEDM-S6 Optimized AVX2 hybrid is a single-message backend using the AVX2
AFS-64 nonlinear layer and the generated opt64 S6 linear layer.
SHA3-512 OpenSSL EVP and SHA3-512 XKCP CompactFIPS202 are single-message
baselines generated by fresh local execution. Batch16 AVX512 norm is
multi-buffer normalized throughput and is not single-message latency.
