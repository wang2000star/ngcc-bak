## Directory Structure

```text

│   ├── MoFang-512/        # Optimized implementation of MoFang-512
│   ├── MoFang-768/        # Optimized implementation of MoFang-768
│   ├── MoFang-768-XOF/    # Optimized implementation of MoFang-768 in XOF mode
│   └── MoFang-1024/       # Optimized implementation of MoFang-1024
└── Reference_Implementation/
    ├── MoFang-256/        # Reference implementation of MoFang-256
    ├── MoFang-256-XOF/    # Reference implementation of MoFang-256 in XOF mode
    ├── MoFang-512/        # Reference implementation of MoFang-512
    ├── MoFang-768/        # Reference implementation of MoFang-768
    ├── MoFang-768-XOF/    # Reference implementation of MoFang-768 in XOF mode
    └── MoFang-1024/       # Reference implementation of MoFang-1024
