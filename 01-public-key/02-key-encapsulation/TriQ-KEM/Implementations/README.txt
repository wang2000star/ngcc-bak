TriQ-KEM implementation package

This directory contains the submitted implementations for the four TriQ-KEM
parameter sets:

- Reference_Implementation/TriQ-KEM-128
- Reference_Implementation/TriQ-KEM-256
- Reference_Implementation/TriQ-KEM-384
- Reference_Implementation/TriQ-KEM-512
- Optimized_Implementation/TriQ-KEM-128
- Optimized_Implementation/TriQ-KEM-256
- Optimized_Implementation/TriQ-KEM-384
- Optimized_Implementation/TriQ-KEM-512

Each instance directory contains a Makefile.  The target `all` builds the
known-answer-test executable, `kat` runs it and writes the output under the
local output/ directory, and `clean` removes generated build artifacts and
local output.

The root-level Test_Vectors directory contains the submitted KAT files.  These
files match the KAT files generated by both the reference and optimized
implementations.

The implementation uses the API_PKC auxiliary hash/XOF functions supplied with
the submission.  The PKE encryption sampler for r1 and r2 uses bounded-density
rejection sampling.  The bounded-density check is implemented with branch-free
maximum tracking in both reference and optimized implementations.

The implementations are intended to be built with GCC in an MSYS2 UCRT64 environment. Reference builds use C99 flags, and optimized builds require the 64-bit x86 instruction-set support specified in the corresponding Makefiles.
