# LWR-KEM
Implementation codes for LWR-KEM (f.k.a. Scabbard): LWR-KEM-128, LWR-KEM-256, LWR-KEM-512.

## :open_file_folder: Contents

- [Reference Implementation](Reference_Implementation/): lwrkem128, lwrkem256, lwrkem512

## :sparkles: Running Code

Compile with:
```shell
make
```

Generate KATs with:
```shell
./genKAT
```

Clean with:
```shell
make clean
```

## Benchmarking

Compile with: 
```shell
make bench_speed
```

Bechmark using:
```shell
bench_speed
```
