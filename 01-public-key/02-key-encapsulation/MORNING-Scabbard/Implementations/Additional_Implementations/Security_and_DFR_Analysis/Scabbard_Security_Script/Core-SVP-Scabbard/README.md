# LW_PQC Leaky-LWE Estimator

This repository contains a small Python/Sage-based implementation for estimating the security of Scabbard parameters using leaky-LWE-Estimator https://eprint.iacr.org/2020/292.pdf.

## Requirements

- Python 3.10+ (or compatible Python 3.x)
- SageMath
- NumPy
- Matplotlib

## Usage

Run the main estimator script from the `Scabbard` directory:

```bash
python3 select_scabbard_params.py
```
