# HARE implementation directories

```text
Reference_Implementation/   Portable C99 KR reference implementation.
Optimized_Implementation/   Main x86 AVX2/PCLMUL KR optimized implementation.
Additional_Implementation/  Additional ARM/SVE KR implementation.
_shared/                    Shared core, API_PKC helpers, tests and public constants.
```

This KR-only package contains the active HARE v1.5 KR `[51,41]_2` covering-code line for all four submission security levels.  Historical hamming regression instances are not included in this package.
