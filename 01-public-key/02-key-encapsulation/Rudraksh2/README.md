# Rudraksh2 Algorithm Package

This repository contains the complete submission package for the Rudraksh algorithm, which includes essential information, algorithm specifications, implementations, test vectors, and supporting documentation.

## Contents

| Path | Description |
|------|-------------|
| `basic_information.pdf` | Basic information about the algorithm and submitters|
| `rudraksh2.pdf` | Main algorithm specification |
| `Implementations/` | Reference, Optimized, Cortex-M4 and supporting implementations |
| `Test_Vectors/` | Test vectors for validation and interoperability testing |
| `Supporting_Documentation/` | Intellectual property statement from the submitters and the implementation owners |
