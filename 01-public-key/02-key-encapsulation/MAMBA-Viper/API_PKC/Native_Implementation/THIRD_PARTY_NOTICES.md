# Third-Party Notices

This repository includes small constant-time comparison and conditional-move utility code adapted from public post-quantum cryptography implementations.

The constant-time comparison and conditional-move utilities are adapted from public CRYSTALS-Kyber implementation material.

The AVX implementation also retains an optional third-party optimized polynomial-multiplication backend under `AVX_Implementation_KEM/tches2021_ntt/`.
That backend keeps its own license and attribution files in place.

This file is intended to centralize third-party notices for the anonymous artifact.
A non-anonymous public release may expand these notices as required by the final distribution policy.
