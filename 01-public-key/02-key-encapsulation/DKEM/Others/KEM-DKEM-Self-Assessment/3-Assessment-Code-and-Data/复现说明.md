# DKEM 自评估复现说明

所有结果以 `DKE_RANDOM=0`（官方确定性 DRNG，种子取自 KAT 输入）产生，**可复现**。

## 1. 功能测试（KAT 正确性）
进入 `../2-Algorithm-Source-Code/Implementations/<版本>/DKEM-<128|256|512>/`，执行：
```
bash build.sh
```
将在该实例的 `output/` 写出 `KAT_KEM_DKEM-<级别>.txt`，与本目录 `Test_Vectors/` 逐字节比对即为功能验证。
参考实现与优化实现的 KAT 均与 `Test_Vectors/` 逐字节一致。

## 2. 性能与资源自评估（指引 §3.3 / §3.5）
- **一键测量脚本：`run_assess.sh`**（首选）。对每个实例自动完成：功能 KAT（PASS/FAIL）、
  **平均时间（µs）**、**平均 CPU 周期**（x86-64 经 `__rdtsc`；arm64 无稳定用户态周期计数器，记为 NA）、
  **峰值常驻内存**（`getrusage(RUSAGE_SELF).ru_maxrss`，KB）、**静态镜像大小**（GNU `size`，text+data+bss）。
  采样量 KEM N=300、KEX N=128（均 ≥100）。脚本按 `uname -m` 自适应
  （x86_64 → Reference+Optimized；aarch64 → Reference+AArch64_NEON），单核。
  运行：`ASSESS_ROOT=<2-Algorithm-Source-Code 所在的 Implementations 父目录> CC=gcc bash run_assess.sh`。
  其内嵌的基准源码（`bench_kem2.c` / `bench_kex2.c`）以 here-doc 形式包含在脚本内，无需外部文件。
- 原始测量输出随包提交于 `Raw-Evidence/`：`assess_x86.txt`（x86-64，含 UTC 起止时间戳）、
  `assess_247.txt`（arm64 Ubuntu gcc）、`assess_143.txt`（arm64 macOS clang 功能 KAT 交叉验证）。
- 兼容保留：`run_all_tests.sh`（NT=128 版 `run_final.sh`）为早期编排脚本；
  在本材料包中，**`run_assess.sh` + 逐实例 `build.sh` 为首选复现方式**。
- Cortex-M4（附加）：`run_m4_tests.sh`（需 `arm-none-eabi-gcc` + `qemu-system-arm`）。

## 3. 目标指令集 / 编译配置
详见 `1-Self-Assessment-Reports/` 内的报告第 3 节（备案信息）：参考 `-std=c99 -Wpedantic -Wall -Wextra -O2`；
x86 优化 `-O3 -march=x86-64 -mavx2 -mtune=native -flto -fomit-frame-pointer`；
arm 优化 `-O3 -march=armv8.2-a -flto -fomit-frame-pointer`。
