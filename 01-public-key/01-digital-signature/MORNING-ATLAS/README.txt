The electronic package for "ATLAS: A Fast and Lightweight Digital Signature from Module Learning with Rounding" includes:

Basic Information: Signed PDF containing submitter details. This is available in the "Basic_Information" folder.

Algorithm Specifications: A detailed specification of our proposal. This is available in "Algorithm_Specifications" folder. The file name is DSA_ATLAS_Specification.pdf

Implementations Folder: Source code for the algorithm. The folder Implementations contains it.  It has four sub-folders and the README file. Four folders correspond to different security levels.

Test_Vectors Folder: Data for verification and testing. These are available in the "Test_Vectors" folder.

IP Statements: Signed PDF regarding Intellectual Property. We placed it inside the "IP_Statements" folder.
