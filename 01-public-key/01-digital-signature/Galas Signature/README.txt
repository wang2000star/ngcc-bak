Galas Signature Scheme - NGCC electronic submission package

This directory contains the technical electronic files prepared in this
workspace:

1. Galas_Signature_Scheme.pdf
   Algorithm text/specification PDF.

2. Implementations/
   Reference and optimized implementation source code.

3. Test_Vectors/
   Known-answer test vectors for all eight signature instances.

4. Self_Evaluation/
   x86 self-evaluation scripts and output locations for timing, cycle,
   throughput, memory, and size measurements.

5. Dependencies.txt
   Third-party dependency and build-tool statement.

The NGCC submission requirements also ask for two signed scanned PDF files:

1. algorithm basic information form;
2. intellectual-property declaration.

Those two files require manual signatures/stamps and are therefore not
generated here.

Submitted instances:

Galas-160S
Galas-160F
Galas-256S
Galas-256F
Galas-384S
Galas-384F
Galas-512S
Galas-512F
