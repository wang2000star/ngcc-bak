TriQ-KEX implementation package

This directory contains the submitted implementations for the four TriQ-KEX
parameter sets:

- Reference_Implementation/TriQ-KEX-128
- Reference_Implementation/TriQ-KEX-256
- Reference_Implementation/TriQ-KEX-384
- Reference_Implementation/TriQ-KEX-512
- Optimized_Implementation/TriQ-KEX-128
- Optimized_Implementation/TriQ-KEX-256
- Optimized_Implementation/TriQ-KEX-384
- Optimized_Implementation/TriQ-KEX-512

Each instance directory contains a Makefile.  The target `all` builds the
known-answer-test executable, `kat` runs it and writes the output under the
local output/ directory, and `clean` removes generated build artifacts and
local output.

The root-level Test_Vectors directory contains the submitted KAT files.  These
files match the KAT files generated by both the reference and optimized
implementations.

The implementation uses the API_PKC auxiliary hash/XOF functions supplied with
the submission.  TriQ-KEX is built from the submitted TriQ-KEM implementation
and therefore uses the same bounded-density rejection sampling code.  The KEX
messages include the UAUB identity labels ID_A and ID_B in M1 and M2.
