# 算法源代码说明

本目录为 `密钥交换-AFS-KEX-ARM-参考实现版` 的源码交付。实现版本映射为 `ref`，覆盖 `AFS-KEX-C128`、`AFS-KEX-C256`、`AFS-KEX-C512` 三个参数集。

| 参数集 | 源码目录 |
| --- | --- |
| AFS-KEX-C128 | `crypto_kex/afs-kex-128/ref` |
| AFS-KEX-C256 | `crypto_kex/afs-kex-256/ref` |
| AFS-KEX-C512 | `crypto_kex/afs-kex-512/ref` |

`Makefile`、`mk/`、`mupq/`、`common/`、`ldscripts/`、`libopencm3/` 为 ARM Cortex-M4 构建与测试框架。`kat.py` 使用 `Test_Vectors/` 中的固定 KAT 文件验证板端输出。
