# 依赖说明

AFS-KEX 参考实现版算法源码不依赖外部第三方密码库。`libopencm3/`、`mupq/`、`common/`、`mk/` 随源码包一并交付，用于 ARM Cortex-M4 构建、烧录和测试。

| 工具/组件 | 本次版本 | 用途 | 必要性说明 |
| --- | --- | --- | --- |
| `arm-none-eabi-gcc` | 13.2.1 20231009 | Cortex-M4 交叉编译 | 复现 ARM 固件构建时需要 |
| GNU Make | 4.3 | 调用构建系统 | 复现构建时需要 |
| Python | 3.12.3 | 运行测试脚本 | 复现测试脚本时需要 |
| `st-flash` | v1.8.0 | 通过 ST-Link 烧录 STM32F4DISCOVERY | 复现实板测试时需要 |
| Host `gcc` | Ubuntu 13.3.0 | Host 侧辅助构建 | 仅复现 host 测试辅助程序时需要 |

Python 包见 `requirements.txt`：`pyserial==3.4`、`tqdm`。若只审阅或集成算法源码，不运行随附测试脚本，则无需安装这些 Python 包。

本次自评估使用 `stm32f4discovery` 实板和 `/dev/ttyUSB0` 串口。
